# Results directory

This directory contains:

- **figures/** – Generated plots, visualizations, figures for papers
- **tables/** – Summary tables, statistical outputs
- **analysis/** – Processed analysis results, summaries
- **logs/** – Experiment logs, performance records

## Reproducibility

All results should be reproducible from experiments in `experiments/` and data in `data/`.

Reference outputs for key results are stored in `reproducibility/reference_outputs/`.

See `ROADMAP.md` for validation and reproducibility criteria.
