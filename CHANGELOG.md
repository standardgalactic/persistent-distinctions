# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-08-07

### Added

- Initial project scaffolding and structure
- Research question, hypotheses, and operationalization framework
- Experimental structure with designated directories for code, data, and results
- Comprehensive project management script (`scripts/manage.sh`)
  - Commands for clean, install, test, run, lint, format, type-check
  - Version management (major/minor/patch bumping)
  - Release automation
- Python project configuration with `pyproject.toml`
- Development dependencies (pytest, black, flake8, isort, mypy, sphinx)
- GitHub Actions CI/CD workflows for testing and releases
- MIT License
- Contributing guidelines
- Expanded README with quick start guide and project layout
- EditorConfig for consistent code formatting
- Enhanced .gitignore for Python projects

### Initial Setup

- Python 3.9+ support
- Core dependencies: numpy, pandas, matplotlib, scipy
- Development tools for code quality assurance
