# Examples

Worked examples and tutorials demonstrating how to use the persistent-distinctions framework.

## Contents

- **baseline_model.py** – Basic complex-systems model without distinctions
- **distinction_model.py** – Model with persistent-distinctions constraint
- **comparison.py** – Side-by-side comparison of baseline vs. distinction models
- **parameter_sweep.py** – Exploring parameter sensitivity

## Running Examples

```bash
python examples/baseline_model.py
python examples/distinction_model.py
python examples/comparison.py
```

See each script for customization options.
