# Notebooks

Jupyter notebooks for interactive exploration and documentation.

## Contents

- **01_introduction.ipynb** – Overview and motivation
- **02_baseline_model.ipynb** – Baseline complex-systems model
- **03_distinctions_principle.ipynb** – Theory and operationalization
- **04_experiments.ipynb** – Running and analyzing experiments
- **05_results_summary.ipynb** – Aggregating and interpreting results

## Usage

```bash
jupyter notebook
```

Then open notebooks in `notebooks/`

## Guidelines

- Use descriptive cell comments
- Include visualizations and explanations
- Link to main documentation
- Save outputs but do not commit `.ipynb_checkpoints/`
